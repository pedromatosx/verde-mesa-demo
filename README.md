# Verde Mesa — demonstração

Demonstração pública com dados fictícios. Catálogo e estoque são simulações em memória; os dados cadastrados desaparecem ao recarregar a página. Vendas, pagamentos e outros módulos ainda estão em desenvolvimento. Não utilize dados pessoais ou de um negócio real.

https://pedromatosx.github.io/verde-mesa-demo/

Ressalva de usabilidade: a organização de Produtos e Caixa foi aprovada com ressalvas em 18/10/2026 e será revista futuramente.

Este repositório contém somente o site compilado. O código-fonte permanece em repositório privado.
